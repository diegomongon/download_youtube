# Download simples de videos do youtube usando pytubefix

## crie um pasta para esse projeto
```bash
mkdir projeto_download_youtube
cd projeto_download_youtube/
```

## ambiente virtual
```bash
python3 -m venv venv
```

## ativando ambiente virtual
```bash
source venv/bin/activate
```

## instalando biblioteca
```bash
pip install pytubefix
```


## testando para validar se está funcionando
```bash
python3 main.py
```
